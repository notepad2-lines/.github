# Notepad2 - Change One Text File on Purpose

Notepad2 is a small editor for text you can explain. It is not a hex patcher and not a place to rewrite Windows. The file on disk changes when you save.

---

## Product Snapshot

Open a file from a folder you own. Look at the encoding. If the letters already look wrong, do not save. Close and reopen the copy you should have made, or leave the original untouched. Change one line you can recognize, save, and open the file again in Notepad2 or in another editor.

Replace-all is the dangerous command. It will change every match, including ones you forgot. Copy the file first. A backup of the editor's settings is not a backup of your document.

## Live Production

Use it for a note, a log you keep, or a config you maintain and have copied. Keep the path visible so you are not editing a temporary download. When you are done, the file should open without Notepad2. Plain text does not need the editor running.

On a shared PC, close the document. A file left open can show private text to the next person.

---

## The Spare Stays

The copy you made before the edit is the way back. Do not delete it in the same sitting as a replace-all. When the reopened line is right, then you may drop the spare.

---

## Setup Path

Prerequisites: A text file you may edit, and a copy if it is the only one.

1. Install Notepad2 and open the file from your folder.
2. Read the encoding. Do not save if the text looks wrong.
3. Change one line and save.
4. Reopen the file and read that line.
5. Use replace-all only on a copy.

## Who Benefits

Notepad2 fits a careful edit of your own text. It does not fit system files, a binary, a replace without a spare, or a save that would rewrite the encoding of a file you have not copied.

---

## Fixes

Characters turned into marks: restore the copy and do not save that encoding. The line vanished after reopen: you saved a different path. Check the title bar. Replace-all went too far: delete the bad copy and use the spare.
